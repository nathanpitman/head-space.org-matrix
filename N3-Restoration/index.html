This intro movie hasn't run since Shockwave died. 102 bitmap frames were pulled back out of its RIFX container byte by byte, decompressed, repainted through their original palette, and set here to fade in once, then loop from the point the shimmer starts repeating — same as it would have, sitting idle on someone's desktop.

Frame 76 and frame 102 are byte-for-byte identical bitmaps — the source movie's own animation repeats on an exact 26-frame cycle, confirmed by diffing every recovered frame against every other. The full capture plays once, then settles into that exact cycle. The tune restarts from its own top; the score gave it no internal loop markers to honour instead.

Frame timing is a reconstruction — the original tempo channel wasn't recovered, so playback runs at a flat 8 fps. Everything else, down to the palette lookup, is read straight from the file.
